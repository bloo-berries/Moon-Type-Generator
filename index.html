Moon Type Generator

Translate English into Grade 1 Moon type – the tactile alphabet of raised curves and angles – as real Unicode text. Unlike an image or a canvas, everything below can be selected, copied, and pasted anywhere.

The alphabet, by shape

Moon built his letters from a handful of base shapes turned in four directions, so readers could learn a few forms rather than twenty-six. Eight letters – C, J, L, N, O, U, V, Z – keep their print forms outright. Hover any tile for its shape and code point.

How the stand-ins work. Moon script has no Unicode block yet, so each letter uses an existing character whose printed form matches the Moon glyph – Λ for A, Γ for E, ∩ for W, and so on. The full table with code points lives in src/moon.js.

Rough edges. H renders as a filled shape (◐) where embossed Moon shows a half-filled circle; Q (⦣) needs a font with mathematical symbols and may show a fallback box in some apps; digits currently pass through untranslated (the library also offers the historical number-sign + A–J convention).

Sources & thanks. Letter shapes follow the descriptions at fakoo.de; background from the Moon type article; inspired by Byron Knoll’s canvas-based generator. Body text is set in Atkinson Hyperlegible, the Braille Institute’s typeface.
